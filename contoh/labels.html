DdDesignReport

Contoh Label produk

Label 10 × 6 cm, satu label per baris data, dengan Code 128 dan QR.

Ubah di designer Unduh PDF Unduh Excel Template JSON

Pratinjau di atas adalah hasil cetak asli DdDesignReport dengan data contoh, bukan gambar.

Pakai di aplikasi Anda

  1. Unduh labels.json. Isinya template dan data contohnya.
  2. Ubah tata letaknya di designer, atau pasang designer-nya di aplikasi Anda agar klien bisa mengubahnya sendiri.
  3. Cetak dari backend dengan data Anda sendiri: Go, Java, Kotlin, Node.js, atau PHP, Python, dan .NET lewat HTTP.
ddreport -format pdf < labels.json > labels.pdf     # atau xlsx, xls, html, csv

Langkah lengkapnya ada di Mulai dalam 5 menit. Butuh disesuaikan dengan format perusahaan Anda, atau dipasangkan sekalian? Lihat jasa.
