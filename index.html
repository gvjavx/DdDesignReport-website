Cara kerjanya

Tiga langkah, tanpa menulis kode tata letak

Yang mendesain tidak perlu bisa memprogram, dan yang memprogram tidak perlu mengatur posisi teks.

  1. Desain

    Buka designer di browser. Sisipkan teks, tabel, gambar, chart, dan barcode, lalu atur dengan ribbon seperti di pengolah kata.

  2. Simpan

    Designer menghasilkan satu template JSON. Tempat data akan muncul ditandai dengan {{nama_field}}.

  3. Cetak

    Backend memanggil satu fungsi: template + data → PDF, HTML, Excel, atau CSV. Hasilnya sama di semua bahasa.

Mulai

Mulai dalam 5 menit

Dari nol sampai PDF pertama. Yang dibutuhkan hanya satu binary.

  1. Unduh binary ddreport

    Satu binary ini menjalankan designer sekaligus menjadi mesin cetak untuk Java, Kotlin, dan Node.js. Ambil yang sesuai sistem Anda dari GitHub Release (ddreport-linux-amd64, ddreport-darwin-arm64, ddreport-windows-amd64.exe, ...) dan ganti namanya menjadi ddreport, atau build sendiri dengan Go:

    git clone https://github.com/gvjavx/DdDesignReport
cd DdDesignReport
go build -o ddreport ./cmd/ddreport

  2. Jalankan designer

    ./ddreport -serve 127.0.0.1:8080

    Buka http://127.0.0.1:8080 di browser.

  3. Pilih template, lalu ubah

    Di bagian atas pilih Templates… → Faktur. Klik ganda judulnya untuk mengganti teks, atau pakai tab Insert untuk menambah elemen.

  4. Lihat hasilnya

    Buka tab View → Preview. Data contohnya ada di Sample data for preview and export dan bisa Anda ganti. Tombol PDF / HTML / XLSX / XLS / CSV mengunduh hasilnya langsung.

  5. Simpan template

    Klik Save template. Anda mendapat report.json; simpan di project atau database Anda.

  6. Cetak dari backend

    Kirim template dan data, terima dokumennya.

    import ddreport "github.com/gvjavx/DdDesignReport"

template, _ := os.ReadFile("report.json")
data := map[string]any{"number": "INV-001", "rows": rows}

pdf, err := ddreport.Render(template, data, "pdf")
    import io.ddreport.DdReport;

String template = Files.readString(Path.of("report.json"));
byte[] pdf = DdReport.render(template, dataJson, "pdf");
Files.write(Path.of("report.pdf"), pdf);
    import io.ddreport.DdReport

val template = File("report.json").readText()
val pdf = DdReport.render(template, dataJson, "pdf")
File("report.pdf").writeBytes(pdf)
    const { renderAsync } = require('ddreport')

const template = JSON.parse(fs.readFileSync('report.json', 'utf8'))
const pdf = await renderAsync(template, { number: 'INV-001', rows }, 'pdf')
fs.writeFileSync('report.pdf', pdf)
    curl -X POST "http://127.0.0.1:8080/render?format=pdf" \
  -d '{"template": {...}, "data": {...}}' -o report.pdf

    Ganti "pdf" dengan "html", "xlsx", "xls", atau "csv" untuk format lain. Detail tiap bahasa ada di Backend.

Memakai designer

Designer terdiri dari ribbon di atas, halaman di tengah, panel properti di kanan, dan bilah status di bawah. Di layar sempit panel properti pindah ke bawah halaman dan terlipat, dan halaman otomatis dipaskan ke lebar layar.

Satuan di designer adalah point: 1px di layar = 1pt di kertas. A4 berukuran 595 × 842.

Designer menjaga elemen tetap di kertas: elemen tidak bisa keluar dari margin kiri dan kanan, dan band otomatis memanjang jika sebuah elemen melewati tepi bawahnya. Elemen baru tidak ditumpuk persis di atas elemen lain.

Panduan

Band: kerangka laporan

Satu konsep ini menjelaskan hampir semua perilaku laporan. Sisanya hanya soal mengisi.

Halaman laporan dibagi menjadi beberapa band (pita mendatar). Setiap band punya aturan kapan ia dicetak. Anda cukup menaruh elemen di band yang tepat; library yang mengurus pengulangan dan ganti halaman.

header tiap halaman
columnHeader tiap halaman
groupHeader awal kelompok
detail baris 1
detail baris 2
detail baris 3
groupFooter akhir kelompok
summary sekali di akhir
footer tiap halaman
  • header · footerDi atas dan di bawah setiap halaman. Untuk logo, judul, nomor halaman.
  • columnHeaderDi bawah header, setiap halaman. Untuk judul kolom tabel, supaya terulang saat tabel berlanjut ke halaman berikutnya.
  • detailDicetak sekali untuk setiap baris data. Seratus baris data berarti seratus kali band ini.
  • groupHeader · groupFooterSebelum dan sesudah tiap kelompok, jika groupBy diisi. Untuk nama kategori dan subtotal.
  • summarySekali saja, setelah baris terakhir. Untuk total, chart, catatan, tanda tangan.
Dokumen tanpa baris data, seperti surat atau sertifikat, cukup memakai header dan summary. Lihat template Surat resmi dan Sertifikat.

Posisi elemen (x, y) dihitung dari sudut kiri atas band-nya. Halaman baru dibuat otomatis saat band berikutnya tidak muat.

Data & placeholder

Data adalah JSON biasa: beberapa field bebas, ditambah daftar baris di bawah kunci rows. Di template, tulis nama field di antara kurung kurawal ganda.

TulisHasil
{{name}}Nilai field name. Di band detail dicari di baris saat ini dulu, lalu di data utama.
{{customer.name}}Field di dalam objek.
{{price:2}}Angka dengan 2 desimal dan pemisah ribuan: 18,000.00. Angka di belakang titik dua = jumlah desimal (0–12).
{{unit-price}} · {{nama barang}}Nama field apa pun boleh dipakai, termasuk yang bertanda hubung atau berspasi, selama placeholder berisi nama itu saja.
{{page}} · {{pages}}Nomor halaman dan jumlah halaman (di header, columnHeader, footer).

Format Indonesia. Isi thousands dengan . dan decimal dengan , (tab Layout → Data) agar {{price:2}} menjadi 18.000,00.

Field yang tidak ada menghasilkan teks kosong. Array baris saja, tanpa objek pembungkus, juga diterima sebagai data. Nama kunci rows bisa diganti lewat dataKey.

Perhitungan & total

Template bisa menghitung sendiri, jadi backend cukup mengirim data mentah.

Saya ingin…Tulis
Jumlah per baris{{qty * price:0}}
Harga setelah diskon{{(price - discount) * qty:0}}
Total semua baris{{sum(qty * price):0}}
Pajak 11% dari total{{sum(qty * price) * 0.11:0}}
Kembalian{{cash - sum(qty * price):0}}
Persentase terhadap total{{qty * price / sum(qty * price) * 100:1}}%
Jumlah baris{{count()}}
Rata-rata, terkecil, terbesar{{avg(price):2}} · {{min(price)}} · {{max(price)}}
Teks sesuai kondisi{{if(paid, 'LUNAS', 'BELUM LUNAS')}} · {{if(stock < minimum, 'Pesan ulang')}}
Huruf besar, pembulatan{{upper(name)}} · {{round(price / 3, 2)}}
Tanggal{{date:dd MMMM yyyy}} → 19 Oktober 2026 · {{now:dd/MM/yyyy HH:mm}} (waktu cetak)
  • Operator: + - * / dan kurung. Perkalian dan pembagian dihitung lebih dulu.
  • Perbandingan = != < > <= >=, digabung dengan and, or, not. Teks ditulis dalam kutip tunggal: status = 'lunas'.
  • Fungsi if(kondisi, jika ya, jika tidak), upper, lower, round(x, desimal).
  • Pola tanggal: yyyy yy MMMM MMM MM M dd d EEEE EEE HH mm ss; teks lain dalam 'kutip'. Nama bulan dan hari berbahasa Indonesia dengan Dates in: Indonesian di tab Layout ("locale": "id"). Tanggal dibaca dari teks ISO (2026-10-19, 2026-10-19T08:30:00Z) atau Unix time.
  • Fungsi sum, avg, min, max, count menghitung atas banyak baris. Isinya boleh berupa perhitungan.
  • count() menghitung semua baris; count(f) hanya baris yang f-nya berupa angka.
  • Di dalam perhitungan, nama field yang bukan satu kata ditulis dalam kurung siku: {{[unit-price] * qty}}, {{sum([harga satuan])}}.
Angka yang dikirim sebagai teks ("18000", seperti dari BigDecimal atau kolom numeric database) juga dihitung. Nilai yang memang bukan angka, pembagian dengan nol, atau hasil yang terlalu besar memberi hasil kosong, bukan angka yang salah. Hasil tanpa :N tidak menampilkan sisa pembulatan: 0.1 + 0.2 menjadi 0.3.

Total yang dipakai di setiap baris, misalnya persentase terhadap total, dihitung sekali saja, jadi laporan besar tetap cepat.

Kelompok & subtotal

Isi Group by (tab Layout) dengan nama field, misalnya category. Baris dengan nilai yang sama dikumpulkan menjadi satu kelompok, urut sesuai kemunculan pertamanya, jadi data tidak perlu diurutkan lebih dulu.

groupBy      category
groupHeader  {{category}} ({{count()}} produk)
detail       {{name}}            {{qty * price:0}}
groupFooter  Subtotal            {{sum(qty * price):0}}
summary      Total               {{sum(qty * price):0}}

Rumus yang sama memberi hasil berbeda tergantung band-nya:

  • di groupHeader, detail, groupFooter: dihitung atas kelompok itu,
  • di summary, header, footer: dihitung atas seluruh baris.

Centang New page per group agar setiap kelompok mulai di halaman baru. Judul kelompok tidak pernah tertinggal sendirian di dasar halaman: jika baris pertamanya tidak muat, keduanya pindah bersama. Kelompok yang berlanjut ke halaman berikutnya mendapat judulnya lagi di atas halaman itu.

Sort by mengurutkan baris lebih dulu, misalnya category, -total (tanda - untuk menurun). Band groupHeader dan groupFooter yang berisi elemen tetap dicetak tanpa Group by, sekali di sekitar semua baris.

Sampai tiga tingkat

Isi Group by dengan beberapa field, misalnya region, city. Band kepala grup 2 / kaki grup 2 (dan 3 untuk field ketiga) muncul di designer di dalam band grup pertama. Setiap tingkat punya subtotalnya sendiri, dan judul semua grup yang sedang berjalan diulang di atas halaman baru.

groupBy       region, city
groupHeader   Wilayah {{region}}
groupHeader2  Kota {{city}}
detail        {{name}}        {{amt:0}}
groupFooter2  Subtotal kota   {{sum(amt):0}}
groupFooter   Total wilayah   {{sum(amt):0}}

Centang A sheet per group agar XLSX dan XLS berisi satu sheet untuk setiap grup tingkat pertama, dinamai sesuai grupnya.

Sub-laporan

Untuk daftar di dalam data yang butuh tata letak sendiri, bukan sekadar tabel: tab Insert → Sub-report, isi rows from data dengan nama daftarnya (misalnya lines), lalu Edit sub-report…. Terbuka designer kedua selebar kotak elemen, dengan band header, column header, grup (sampai tiga tingkat), detail, dan summary; Sort by dan Group by-nya bisa diisi sendiri. Band footer-nya tidak dipakai.

  • Di band detail laporan induk, setiap baris mendapat sub-laporannya: setiap pesanan dengan rincian per jenisnya, setiap pegawai dengan riwayatnya.
  • Field induk tetap bisa dipakai di dalamnya ({{number}}); {{index}} adalah nomor item; agregat di header dan summary-nya menghitung semua item.
  • Band induk ikut memanjang. Sub-laporan yang lebih panjang dari satu halaman berlanjut tanpa memotong band-nya, dengan header dan column header diulang.
  • Di Excel dan CSV, setiap baris sub-laporan menjadi baris spreadsheet.

Teks panjang: centang Wrap

Tanpa Wrap (grow), teks yang melebihi kotaknya terpotong. Dengan Wrap, teks turun ke baris berikutnya dan band ikut bertambah tinggi: elemen di bawahnya turun, dan kotak serta garis tegak di sekelilingnya ikut memanjang. Kata yang lebih lebar dari kotaknya (URL, nomor panjang) dipecah di tengah.

Teks yang lebih panjang dari satu halaman, misalnya isi surat, berlanjut ke halaman berikutnya baris demi baris, tanpa ada yang terpotong. Footer yang memanjang tetap berada di dalam margin bawah.

Tampil jika

Setiap elemen punya kolom show when (showIf) di panel kanan, misalnya paid = 'yes' atau stock < minimum. Jika kondisinya salah, elemen tidak dicetak; di Excel dan CSV selnya kosong. Elemen dengan kondisi diberi garis putus-putus jingga di designer. Kondisi yang salah tulis tetap menampilkan elemennya agar kesalahannya terlihat.

Beberapa teks Wrap dalam satu band saling memperhitungkan: teks yang bertumpuk mendorong bergantian (dorongannya dijumlahkan), sedangkan teks yang bersebelahan mengikuti yang paling tinggi.

Gambar

Gambar disimpan di dalam template sebagai data URI (data:image/png;base64,…); designer melakukannya otomatis saat Anda memilih file. Alamat gambar di internet tidak diterima, begitu pula SVG dan WebP: pencetakan gagal dengan pesan image: src must be a PNG, JPEG or GIF data URI.

Gambar juga bisa diambil dari data: isi picture from data dengan placeholder, misalnya {{photo}}, dan kirim data URI di field itu (foto produk, tanda tangan, logo per perusahaan). Gambar yang kosong atau rusak dibiarkan kosong tanpa menggagalkan laporan.

Format teks

Pilih elemen, lalu pakai grup Font dan Paragraph di tab Home: jenis font (lihat Font), ukuran, bold, italic, underline, warna teks, highlight, rata, dan spasi baris.

Format sebagian teks

Di designer: klik ganda teksnya, blok kata yang dimaksud, tekan B / I / U. Di JSON hasilnya berupa tag <b>, <i>, <u>:

Total: <b>{{sum(price):2}}</b> <i>(belum termasuk pajak)</i>

Hanya tiga tag itu yang dikenali. Tanda < lain, termasuk yang berasal dari data, dicetak apa adanya, jadi data pengguna tidak bisa menyisipkan HTML. Untuk mencetak tulisan <b> itu sendiri, tulis &lt;b>; designer melakukannya otomatis saat Anda mengetiknya.

Huruf yang tidak ada di font PDF bawaan (aksara non-Latin, emoji) dicetak sebagai ?. Pakai salah satu font bundel atau font sendiri; lihat Font.

Tabel

Tab Insert: isi jumlah baris × kolom, klik Table. Klik ganda sel untuk mengisi; isinya boleh placeholder. Di panel kanan atur jumlah baris dan kolom, lebar kolom (3,1,1 = kolom pertama tiga kali lebih lebar), tebal dan warna garis. Klik sebuah sel lalu tombol rata untuk mengatur rata kolom itu.

Sel: warna sendiri dan sel gabungan

Klik sebuah sel. Bagian Sel di panel kanan mengatur warna latar, warna teks, rata, tebal, dan miring sel itu saja, di atas gaya baris dan kolomnya. Tombol Merge right dan Merge down menggabung sel dengan tetangganya (teksnya ikut dipindahkan, tidak ada yang hilang), Unmerge memisahkannya lagi. Gaya dan gabungan ikut bergeser saat baris atau kolom disisipkan atau dihapus.

  • Seret garis antar kolom atau antar baris pada tabel terpilih untuk mengubah lebar kolom dan tinggi baris; angkanya juga bisa diisi di column widths dan row heights.
  • cell padding mengatur jarak teks dari tepi sel (kosong = 3pt mendatar, 2pt tegak).
  • Saat mengetik di sel: Enter menyimpan, Shift+Enter baris baru, Tab / Shift+Tab ke sel berikutnya / sebelumnya. Sebagian teks sel bisa dibuat tebal, miring, atau bergaris bawah seperti di text box.
  • Sel yang disalin dari Excel bisa langsung ditempel (Ctrl+V) ke tabel, mulai dari sel yang diklik; baris dan kolom ditambah bila perlu.

Tabel data: daftar di dalam data

Isi rows from data dengan nama daftar di data, misalnya items. Baris judul dan baris total dicetak sekali; baris di antaranya diulang untuk setiap item. Di baris yang diulang, {{name}} adalah field item dan {{index}} nomor urutnya; di judul dan baris total, {{sum(qty * price):0}} dan {{count()}} menghitung semua item. Di designer tabel ini bertanda ↻ items.

{ "number": "SO-1", "items": [ { "name": "Kopi", "qty": 2, "price": 18000 }, ... ] }

Taruh tabel data di band detail untuk mencetak daftar di setiap baris (setiap pesanan dengan itemnya sendiri), atau di summary untuk daftar di data utama. Tabel yang lebih panjang dari satu halaman berlanjut ke halaman berikutnya tanpa memotong baris, dan baris judulnya diulang di atas setiap halaman. Di XLSX dan CSV setiap item menjadi satu baris; warna latar dan warna teks sel ikut ke XLSX dan XLS.

Tabel yang barisnya mengikuti data

Pakai dua tabel satu baris dengan lebar kolom yang sama:

  1. di band columnHeader: judul kolom (bold, beri warna latar),
  2. di band detail: placeholder, misalnya {{name}}, {{qty}}, {{qty * price:0}},
  3. opsional, di band summary: baris total dengan {{sum(qty * price):0}}; centang total row agar bergaya footer.

Di pola ini tiap baris data adalah tabelnya sendiri, jadi banded rows tidak berlaku; beri warna judul lewat header row pada tabel judul.

Karena band detail dicetak sekali per baris data, hasilnya satu tabel utuh. Centang Wrap pada tabel detail agar baris ikut tinggi saat isinya panjang. Kolom tabel ini juga menjadi kolom di Excel dan CSV. Lihat template Faktur dan Daftar stok.

Chart

Chart menggambar data baris. Isi label dengan field pengelompok dan value dengan field angka atau perhitungan. Nilai dengan label yang sama dijumlahkan, jadi label: category dan value: qty * price langsung memberi penjualan per kategori.

Bagaimana desain menjadi tabel Excel

Untuk XLSX, XLS, dan CSV, setiap teks dan sel tabel di band detail menjadi satu kolom, urut seperti dibaca: dari atas ke bawah, lalu kiri ke kanan. Setiap baris data menjadi satu baris.

Band lain (judul kolom, judul dan subtotal kelompok, ringkasan) menambah satu baris untuk setiap baris teksnya. Tiap teks masuk ke kolom yang sejajar dengannya, sehingga subtotal jatuh tepat di bawah kolom angkanya. Band header dan footer tidak ikut.

Laporan tanpa band detail, seperti surat atau sertifikat, tidak punya kolom: teksnya diekspor baris demi baris seperti dibaca, termasuk band header.

  • Teks yang isinya tepat satu placeholder angka, seperti {{qty * price:2}}, ditulis sebagai angka.
  • xls ditulis sebagai XML Spreadsheet 2003. Excel menampilkan satu peringatan bahwa format dan ekstensi berbeda; pilih Yes.
  • CSV diawali BOM UTF-8 agar Excel membaca huruf seperti é dengan benar. Untuk Excel berbahasa Indonesia atau Eropa, yang memakai ; sebagai pemisah, pilih CSV separator ; di tab Layout.
  • Di CSV, teks yang berawalan seperti formula (=, @, +, -) diberi tanda kutip tunggal di depan, supaya isian pengguna tidak dijalankan sebagai formula. Angka seperti -5 tidak diubah.

Bagaimana cara…?

Jawaban singkat untuk hal yang paling sering ditanyakan.

…menampilkan "Halaman 1 dari 5"?

Taruh teks Halaman {{page}} dari {{pages}} di band footer.

…menaruh total tepat di bawah tabel?

Taruh teks {{sum(qty * price):0}} di band summary, rata kanan, dengan tepi kanan yang sama dengan kolom jumlahnya. Band summary dicetak tepat setelah baris terakhir.

…membuat baris tabel berbingkai yang mengikuti data?

Tabel satu baris di columnHeader untuk judul, tabel satu baris di detail untuk isi. Lihat Tabel.

…membiarkan deskripsi panjang turun ke baris berikutnya?

Pilih teks atau tabelnya, centang Wrap di tab Home. Baris akan memanjang sesuai isinya.

…menulis angka dengan format rupiah?

Di tab Layout → Data isi pemisah ribuan . dan desimal ,. Lalu tulis Rp {{price:0}}.

…memasang kop surat atau watermark?

Tab Layout → Background → Picture, pilih gambar seukuran kertas. Atau susun kop dari teks dan garis di band header seperti template Surat resmi.

…mencetak satu halaman untuk setiap pelanggan?

Isi Group by dengan field pelanggan dan centang New page per group.

…mencetak satu label per barang?

Buat kertas seukuran label dan beri band detail tinggi yang sama dengan area cetaknya. Setiap baris data akan menempati satu halaman. Lihat template Label produk.

…menambahkan QR untuk verifikasi dokumen?

Tab Insert → Barcode, format qr, isi https://situsanda.example/verify/{{id}}.

…membuat laporan mendatar (landscape)?

Tab Layout → Orientation → Landscape.

…membuat dokumen tanpa tabel, seperti surat?

Kosongkan band detail. Taruh kop di header dan isi surat di summary; centang Wrap pada paragrafnya agar bagian tanda tangan turun mengikuti panjang isi.

…menampilkan huruf Arab, Jepang, atau aksara lain di PDF?

Berikan font TrueType yang memuat aksara itu. Lihat Font.

Backend

Memanggil dari backend

Satu fungsi di setiap bahasa: template + data + format → dokumen.

Go memakai library-nya langsung, tanpa binary.

go get github.com/gvjavx/DdDesignReport
import ddreport "github.com/gvjavx/DdDesignReport"

template, _ := os.ReadFile("invoice.json")
data := map[string]any{
    "number": "INV-001",
    "rows":   rows, // slice of struct atau map
}

// "pdf" | "html" | "xlsx" | "xls" | "csv"
pdf, err := ddreport.Render(template, data, "pdf")

data boleh berupa apa pun yang bisa di-marshal ke JSON: map, struct dengan tag json, atau json.RawMessage. Nama field di placeholder mengikuti nama JSON-nya.

Dari Maven Central (io.github.gvjavx:ddreport): tambahkan wrapper-nya dan binary untuk sistem tempat aplikasi berjalan, dengan classifier linux-x64, linux-arm64, windows-x64, windows-arm64, darwin-x64, atau darwin-arm64. Tidak ada dependency lain; DDREPORT_BIN menunjuk binary ddreport lain bila perlu.

<dependency>
  <groupId>io.github.gvjavx</groupId>
  <artifactId>ddreport</artifactId>
  <version>0.1.3</version>
</dependency>
<dependency>
  <groupId>io.github.gvjavx</groupId>
  <artifactId>ddreport</artifactId>
  <version>0.1.3</version>
  <classifier>linux-x64</classifier>
</dependency>
import io.ddreport.DdReport;

byte[] pdf = DdReport.render(templateJson, dataJson, "pdf");
Files.write(Path.of("report.pdf"), pdf);

Dua argumen pertama adalah string JSON; serialisasikan objek data dengan Jackson atau Gson. Kegagalan dilempar sebagai IOException.

Kotlin memakai class Java yang sama dari Maven Central: implementation("io.github.gvjavx:ddreport:0.1.3") dan runtimeOnly("io.github.gvjavx:ddreport:0.1.3:linux-x64"), dengan classifier untuk sistem tempat aplikasi berjalan.

import io.ddreport.DdReport

val xlsx = DdReport.render(templateJson, dataJson, "xlsx")
File("report.xlsx").writeBytes(xlsx)

Binary untuk sistemnya ikut terpasang (paket @ddreport/<sistem>); DDREPORT_BIN menunjuk binary ddreport lain bila perlu.

npm install ddreport
const { renderAsync } = require('ddreport')

const pdf = await renderAsync(template, data, 'pdf') // Buffer
res.type('application/pdf').send(pdf)

template dan data adalah objek biasa. renderAsync mengembalikan Promise dan tidak memblokir event loop; render adalah versi sinkronnya. Keduanya melempar Error berisi pesan dari binary jika gagal.

Dari bahasa apa pun, lewat mode -serve.

ddreport -serve 127.0.0.1:8080

curl -X POST "http://127.0.0.1:8080/render?format=pdf" \
  -d '{"template": {...}, "data": {...}}' -o report.pdf

Respons berisi dokumen dengan Content-Type yang sesuai, atau status 400 dengan pesan error. Ukuran body dibatasi 32 MB, dan koneksi yang macet diputus otomatis.

Endpoint ini tidak punya autentikasi. Jalankan di 127.0.0.1 atau di belakang backend Anda sendiri, jangan dibuka langsung ke internet.

Memasang designer di aplikasi Anda

Designer adalah satu file ES module tanpa dependency dan tanpa build step. Pasang dari npm, atau salin designer/designer.js:

npm install ddreport-designer
import { createDesigner, emptyTemplate } from 'ddreport-designer'

const designer = createDesigner(document.getElementById('designer'), {
  template: savedTemplate,
  onChange: template => save(template),
  preview: async template => {
    const res = await fetch('/api/report/preview', {
      method: 'POST',
      body: JSON.stringify(template),
    })
    return res.text()
  },
})

designer.getTemplate()      // salinan template saat ini
designer.setTemplate(other) // mengganti template; pengguna bisa membatalkannya dengan Ctrl+Z
OpsiKeterangan
templateTemplate awal. Kosongkan untuk mulai dari A4 kosong. Template yang rusak atau dari versi lama diperbaiki saat dimuat, bukan ditolak.
theme'light' (default), 'dark', atau 'auto' untuk mengikuti pengaturan sistem. Kertas laporannya sendiri selalu putih.
lang'en' (default) atau 'id' untuk antarmuka berbahasa Indonesia. Di aplikasi standalone: tambahkan ?lang=id pada alamatnya, atau klik tautan bahasa di kanan atas.
onChange(template)Dipanggil setiap ada perubahan. Objeknya adalah objek kerja designer, jangan diubah; pakai getTemplate() jika butuh salinan.
fontBaseOpsional. URL tempat font bundel disajikan, misalnya '/fonts/' (ddreport -serve menyajikannya di sana; di Go, sajikan ddreport.BundledFonts). Tanpa ini kanvas memakai font yang terpasang di perangkat; hasil cetak tidak terpengaruh.

Hasilnya tampil per halaman, dipaskan ke lebar dialog, dengan jumlah halaman; jika fungsi ini melempar error, pesannya ditampilkan di dialog.

Dokumentasi ini memakai nama tombol versi Inggris (Home, Insert, Layout, View, Wrap); dengan lang: 'id' namanya menjadi Beranda, Sisipkan, Tata Letak, Tampilan, Bungkus.

Designer mengisi elemen tempatnya dipasang dan menyesuaikan diri dengan lebar elemen itu, bukan lebar jendela, jadi tetap rapi di dalam panel samping atau dialog. Beri elemen itu tinggi (misalnya height: 80vh) agar halaman bisa digulir di dalamnya. Warna aksen bisa diganti lewat CSS: .ddr { --a: #0f766e }.

Bisa dipakai di framework apa pun: panggil createDesigner pada elemen DOM setelah komponen ter-mount. Template siap pakai ada di designer/templates/; tiap file berisi template dan data contohnya.

export DDREPORT_FONTS=/path/ke/fonts-saya

Lalu tambahkan namanya ke designer: createDesigner(el, { fonts: ['Inter'] }).

Mengganti font bawaan

Untuk aksara yang tidak ada di font bundel (Arab, Jepang, dan sebagainya), Anda juga bisa mengganti font bawaan PDF untuk seluruh laporan:

// set sekali saat aplikasi mulai
ddreport.Font, _ = os.ReadFile("NotoSans-Regular.ttf")
ddreport.FontBold, _ = os.ReadFile("NotoSans-Bold.ttf") // opsional
export DDREPORT_FONT=/fonts/NotoSans-Regular.ttf
export DDREPORT_FONT_BOLD=/fonts/NotoSans-Bold.ttf

Jika font bold tidak diberikan, teks bold memakai font regular. Dengan font pengganti, pilihan Helvetica/Times/Courier diabaikan dan italic memakai bentuk tegak; font bundel dan font yang didaftarkan tetap dipakai apa adanya.

Binary ddreport

Java, Kotlin, dan Node.js mencetak lewat binary ddreport, sehingga hasilnya identik dengan Go. Paket npm dan Maven sudah membawa binary untuk Windows, Linux, dan macOS (x64 dan arm64). Untuk memakai binary lain, unduh dari GitHub Release atau build sendiri, lalu taruh di PATH atau tunjuk lewat DDREPORT_BIN.

go build -o ddreport ./cmd/ddreport
export DDREPORT_BIN="$PWD/ddreport"
go build -o ddreport.exe ./cmd/ddreport
$env:DDREPORT_BIN = "$PWD\ddreport.exe"

Binary membaca {"template": ..., "data": ...} dari stdin dan menulis dokumen ke stdout:

ddreport -format pdf < request.json > report.pdf
Flag / variabelKeterangan
-formatpdf (default), html, xlsx, xls, csv
-serve alamatMenjalankan designer (dengan template siap pakai) dan endpoint POST /render
DDREPORT_BINLokasi binary, dibaca oleh wrapper Java dan Node.js
DDREPORT_FONT · _BOLDFont pengganti untuk seluruh laporan. Lihat Font
DDREPORT_FONTSFolder font tambahan (Nama-Regular.ttf, ...). Lihat Font

Jika gagal, binary keluar dengan kode 1 dan pesan di stderr; wrapper meneruskannya sebagai exception.

Test

Core Go punya unit test untuk setiap bagian mesin cetak (placeholder, perhitungan, format angka, pembungkusan teks, tabel, chart, barcode, ganti halaman, ekspor), test keamanan terhadap template berisi HTML berbahaya, dan test yang mencetak setiap template siap pakai ke semua format. Wrapper diuji terhadap binary sungguhan.

Designer punya halaman test sendiri: sajikan folder designer/ dengan web server (npx serve designer) lalu buka /test.html. Halaman itu menjalankan 97 pemeriksaan pada designer dan menampilkan yang gagal.

Batasan

  • Pengelompokan sampai tiga tingkat.
  • Chart di kanvas designer digambar dari data contoh tanpa skala nilai, dan QR code di kanvas adalah gambaran bentuknya; kode yang bisa dipindai dan chart lengkap ada di hasil cetak dan Preview.
  • XLSX dan XLS membawa bold, format angka, lebar kolom, warna latar, dan warna teks; garis sel dan gabungan sel tidak.
  • Wrapper Java, Kotlin, dan Node.js menjalankan satu proses per dokumen, dengan batas waktu 1 menit (bisa diubah). Di Node.js, pakai renderAsync agar server tidak terblokir selama proses itu berjalan.
  • Designer diuji otomatis di Chromium (Chrome, Edge), Firefox, dan WebKit (mesin Safari) di setiap push; perangkat layar sentuh sungguhan belum diuji.
